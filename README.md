# Awesome Todo App

A small React daily planner for managing tasks, blocking out routine time, and exporting a calendar file.

## Features

- Create tasks with due dates, start times, duration, category, and priority.
- Review one day at a time with a timeline and completion summary.
- Mark tasks complete or delete them from the selected day.
- Persist tasks in the browser with `localStorage`.
- Export the current task list as an `.ics` calendar file.

## Getting Started

```bash
npm install
npm run dev
```

## Validation

```bash
npm test
npm run build
```
